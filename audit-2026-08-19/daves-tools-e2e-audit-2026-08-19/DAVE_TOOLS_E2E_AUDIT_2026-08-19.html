Highest-risk defects

Count integrity

Preflight counts phase-fix-status.json as new assets, producing 49 from 36 unique phase rows plus 13 duplicates.

False launchers

Skills, GUIs, CLIs, services and benchmarks are converted to generic npx -y <slug> child “servers.”

No child proof

The test lists management tools and runs the broken recommender. It never enables, calls, disables, crashes or recovers a child.

Routing bug

All 36 registry entries include an empty tag; every task matches it, so nearly the whole catalog is recommended.

Schema loss

Child descriptions and input schemas are replaced with generic text and an empty object, making reliable calls impossible.

No operator surface

There is no GUI for install, profile selection, health, permissions, repair, evidence, resume or release.

Target shape

Do not target a bigger raw MCP count. Target a smaller, typed and certified control plane: about 16 current MCP candidates, selected additional adapters, skill packs, dependencies and services loaded by project profile. HermesProof should gate and record every mutation and release.

Remediation sequence

0 — Truth reset

Withdraw the 49-installed claim, deduplicate inventory, freeze the current generated registry and make README/status derive from unique typed records.

1 — Typed registry

Use the included JSON schema. Separate MCP servers, skills, CLIs, GUIs, services, benchmarks, runtimes and marketplaces. Record source ref, license, checksum, runtime, permissions and verification.

2 — Correct installers

Remove the generic npx fallback. Use official release, Winget, uv/venv, npm, Gradle/Java, dotnet, Cargo, Docker or remote HTTP installers with exit-code checks and rollback.

3 — Runtime supervisor

Preserve child schemas and descriptions; support stdio and HTTP; add startup/call deadlines, cancellation, process-exit monitoring, retry/backoff, circuit breakers, concurrency control and orphan cleanup.

4 — Security and HermesProof

Use read-only defaults, scoped roots, host/device allowlists, secret references, redaction and structured proof events for install/start/call/test/release/recovery.

5 — Skills and profiles

Implement P0 skills first. Build project profiles for web, Android dev/RE, Windows dev/RE, Unity RE, game creation, media/3D, infrastructure, local AI and embedded.

6 — Domain certification

Each true MCP must pass source, install, protocol, schema, safe-tool, failure/recovery and domain fixture gates before being marked healthy.

7 — Operator GUI and release

Provide Dave a compact Windows dashboard for one-click install, profiles, health, repair, approvals, progress, evidence, resume, release and GitHub/GitLab mirror status.
