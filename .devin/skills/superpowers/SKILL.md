# superpowers

**Use when:** building or extending a non-trivial software feature.

## Steps
- Capture the user goal in one plain-language sentence.
- Tease out a concise spec and break it into readable sections.
- Get explicit sign-off on the spec.
- Build an implementation plan a junior engineer could follow.
- Use red/green TDD, YAGNI, and DRY.
- Dispatch subagents and run a two-stage review: spec compliance then code quality.

## Proof required
- Approved spec section.
- Implementation plan with tests.
- Subagent review completion report.
