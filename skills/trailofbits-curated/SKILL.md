# trailofbits-curated

**Use when:** the task involves a security review, audit, or risky code change.

## Steps
- Load the appropriate Trail of Bits resource for the target language or framework.
- Run static analysis and look for common vulnerability classes.
- Check dependencies for known advisories.
- Report findings with severity and recommended fixes.
- Do not modify code without an explicit security remediation scope.

## Proof required
- Tools invoked.
- Findings list with severity.
- Remediation plan if any.
